游戏规则：
- 1.游戏人数：2人  竞技类  回合制
- 2.游戏目标：每名玩家拥有总计五点血量，使对方血量优先降低至0以取得胜利
- 3.游戏准备：每人以六张卡牌进行游戏，五张置于战斗区（前方），一张置于备战区（后方）。
- 4.游戏流程：
游戏共分为两个大阶段：白昼→黑夜
每个大阶段分为两个小阶段：
白昼：技能阶段→屠杀阶段
黑夜：午夜阶段→备战阶段
每个玩家开局获得三枚“佣金”，随机先后手，并按以下游戏流程进行游戏：
游戏开始→每名玩家获得3佣金→进入白昼→进入技能阶段（从先手开始，双方依次使用技能，直至双方都结束技能阶段）→进入屠杀阶段（从后手开始，双方依次使用技能，直至双方都结束屠杀阶段）→进入黑夜→进入午夜阶段（从先手开始，双方依次使用技能，直至双方都结束午夜阶段）→进入替换阶段（从后手开始，双方可以选择是否花费一点体力，使备战区的一名角色与战斗区任意角色进行调换，该行为不可见，每晚最多一次）→结束这一天→切换先后手→开启第二天
- 5.游戏机制：
①每一天结束后，双方各获得两枚“佣金”，每两天结束后，双方获得一次选择祝福卡的机会，祝福卡仅可在对应阶段使用
②每个技能只可在其对应阶段使用，每个同名技能每天只可使用一次（包括祝福卡）
③每张卡牌有其对应的价值，卡牌死亡后不翻开，但扣除等同于其价值数的生命
④当一方不使用技能时，视为其结束了该小阶段，由另一方一直释放技能直至其主动结束
